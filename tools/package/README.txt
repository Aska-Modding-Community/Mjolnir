Mjolnir {version} - a mod loader and modding SDK for ASKA

Install
  1. Unpack this archive into the game's folder, the one with Aska.exe
     (Steam: right-click ASKA > Manage > Browse local files).
  2. Start the game from Steam. At the first start, and after each game update, Mjolnir prepares itself
     for the game's version for about half a minute; a small window shows how far it is.
  3. Put mods into Mjolnir\Mods, each in a folder of its own.

Start once without mods: add --no-mods to the game's launch options, or create a file Mjolnir\disable.
Uninstall: delete version.dll from the game's folder (and the Mjolnir folder with your mods and settings).
Log: Mjolnir\LogOutput.log.

Mjolnir {version} - загрузчик модов и SDK для ASKA

Установка
  1. Распакуйте архив в папку игры, где лежит Aska.exe
     (Steam: ПКМ по ASKA > Управление > Просмотреть локальные файлы).
  2. Запустите игру из Steam. При первом запуске и после каждого обновления игры Mjolnir около полуминуты
     готовится к её версии; ход показывает небольшое окно.
  3. Кладите моды в Mjolnir\Mods, каждый в свою папку.

Запуск без модов: параметр запуска --no-mods или файл Mjolnir\disable.
Удаление: удалите version.dll из папки игры (и папку Mjolnir с модами и настройками).
Журнал: Mjolnir\LogOutput.log.
